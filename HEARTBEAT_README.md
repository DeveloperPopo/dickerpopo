- View comprehensive stats dashboard

### 💡 Insights & Analytics
- Discover who you connect with most

### 🎮 Gamification System
- **Level System**: Earn XP and level up as you nurture connections
- **XP Rewards**:

  - Connection goal completed: 50 XP

## 📦 Installation

### Quick Start

```bash
# Clone the repository
git clone https://github.com/DeveloperPopo/dickerpopo.git
cd dickerpopo

# Install dependencies (or it installs automatically on first run)
pip install rich

# Make executable (Linux/Mac)
chmod +x heartbeat.py

# Run it!
python3 heartbeat.py

# Or if you made it executable:
./heartbeat.py
```

### Install Globally

```bash
# Create a symlink to run from anywhere (Linux/Mac)
sudo ln -s $(pwd)/heartbeat.py /usr/local/bin/heartbeat

# Now you can run it from anywhere:
heartbeat
```

### Requirements
- Python 3.7+
- Rich library (for beautiful terminal UI)

## 🎮 How to Use

### First Time Setup

When you first run Heartbeat, it will:
1. Welcome you and ask for your name
2. Create a data directory at `~/.heartbeat/`
3. Initialize your data file with default values
4. Show you the main menu

### Main Menu Options

1. **👥 Add New Relationship** - Add someone to your circle
2. **💬 Log Interaction** - Record a connection event
3. **🌟 Log Act of Kindness** - Track compassionate actions
4. **📋 View All Relationships** - See everyone in your circle with status
5. **⏰ Connection Reminders** - See who needs your attention
6. **📊 View Statistics** - Comprehensive stats dashboard
7. **💡 Insights & Analytics** - Deep insights about your patterns
8. **💝 Get Motivated** - Inspirational quotes and encouragement
9. **❌ Exit** - Leave the app

### Recommended Usage Patterns

#### Weekly Review (10 minutes)
1. Open Heartbeat
2. Check connection reminders (option 5)
3. Review all relationships and their status (option 4)
4. Reach out to 2-3 people who need attention
5. Log those interactions afterwards

#### After Social Events
1. Open Heartbeat immediately after connecting with someone
2. Log the interaction while it's fresh (option 2)
3. Rate the quality and note what made it meaningful
4. Get instant XP reward and motivation

#### Daily Kindness Practice
1. Do something kind for someone
2. Log it in Heartbeat (option 3)
3. Reflect on impact and how it made you feel
4. Build a kindness habit streak

#### Monthly Insights
1. View comprehensive statistics (option 6)
2. Review insights and analytics (option 7)
3. Identify relationships that need more attention
4. Set intentions for the coming month
5. Celebrate your consistency and growth

## 🛠️ Troubleshooting

### "rich module not found"
```bash
pip install rich
```

### "Permission denied"
```bash
chmod +x heartbeat.py
```

### "Data not saving"
Check that `~/.heartbeat/` directory is writable:
```bash
ls -la ~/.heartbeat/
```

### Start Fresh
To reset all data and start over:
```bash
rm -rf ~/.heartbeat/
```
