# 🚀 Momentum Quick Start Guide

Get started transforming your life in 3 minutes!

## Installation

```bash
# 1. Install the dependency
pip install rich

# 2. Run Momentum
python3 momentum.py
```

That's it! The tool will auto-install dependencies if needed.

## Your First Session

### Step 1: Morning Check-in (2 minutes)
1. Launch Momentum: `python3 momentum.py`
2. Press `1` for "Daily Check-in"
3. Choose `morning`
4. Set 3 intentions for today:
   - Example: "Complete the project report"
   - Example: "Exercise for 30 minutes"
   - Example: "Call Mom"
5. Write what you're grateful for
6. Rate your energy level (1-10)

**Result**: You'll earn 10 XP and start your day with intention! ☀️

### Step 2: Create Your First Goal (1 minute)
1. Press `2` for "Manage Goals"
2. Press `1` to add a new goal
3. Enter a goal title (e.g., "Read 12 books this year")
4. Choose a category (e.g., "learning")
5. Set target to 12 (books)

**Result**: You'll earn 20 XP and have your first trackable goal! 🎯

### Step 3: Add a Daily Habit (1 minute)
1. Press `3` for "Manage Habits"
2. Press `1` to add a new habit
3. Enter habit name (e.g., "Morning meditation")
4. Choose "daily" frequency

**Result**: You'll earn 15 XP! Now you can track this habit daily! ⚡

### Step 4: Log Your First Habit Completion (30 seconds)
1. Still in Habits menu, press `2` to log completion
2. Enter `1` (the habit number)

**Result**: +15 XP, and you've started your first streak! 🔥

## Level System

- **Level 1**: 0-100 XP
- **Level 2**: 100-200 XP
- **Level 3**: 200-300 XP
- And so on...

### How to Earn XP
- Morning/Evening check-in: **10 XP each**
- New goal: **20 XP**
- New habit: **15 XP**
- Log habit: **15 XP**
- Update goal progress: **10-30 XP**
- Complete goal: **50 XP** 🎉
- Mood tracking: **5 XP**
- Journal entry: **10 XP**

## Pro Tips

1. **Start Small**: 2-3 goals, 3-5 habits max to begin
2. **Be Consistent**: Daily check-ins are the most powerful feature
3. **Don't Break Streaks**: Habit streaks are incredibly motivating
4. **Review Weekly**: Use insights to understand your patterns
5. **Celebrate Wins**: Take time to appreciate your progress

## Data Location

All your data is stored in: `~/.momentum/data.json`

- Fully private and local
- Easy to backup
- Human-readable JSON format

## Getting Help

If you get stuck:
1. Check the README.md for full documentation
2. All data is saved automatically
3. You can exit anytime with option `9`
4. Press `Ctrl+C` to quit immediately (data is still saved!)
